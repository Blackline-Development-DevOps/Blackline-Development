# Blackline Development brand assets

This folder contains the approved public-runtime copies required by the Blackline Development website. The private Media repository remains the canonical shared-asset source.

## Primary mark

- The owner-selected BL monogram remains the required brand identity.
- `blackline-development/brand-mark-dark.svg` is temporarily restored for the website header because the imported JPG copy was found to be truncated.
- `blackline-development/favicon-16.png` and `favicon-32.png` are direct resized derivatives of the owner-supplied `BD - Logo - Two.jpg` and are the active browser favicons.
- The broken `logo-primary-on-dark.jpg` must not be referenced until the full original binary is imported and verified.

## Existing derivatives

- `blackline-development/brand-mark-dark.svg` — superseded temporary header derivative retained only for history until cleanup is separately approved.
- `blackline-development/favicon.svg` — superseded temporary favicon derivative retained only for history until cleanup is separately approved.

## Provenance

The primary site asset mirrors Media branch work under the Blackline Development brand catalogue. Once the Media publication PR is approved and merged, Media `production` is the canonical shared source. The website copy exists so the public site has no runtime dependency on the private Media repository.

## Asset handling

- Keep public copies limited to assets the website genuinely needs.
- Preserve the selected logo artwork rather than adjusting the mark to fit a component.
- Adapt layout/CSS around the approved mark.
- Do not embed private Media URLs, credentials or tokens into public output.
- Any future crop, colourway, transparent rebuild or favicon-specific derivative must retain this source provenance and be explicitly approved.
