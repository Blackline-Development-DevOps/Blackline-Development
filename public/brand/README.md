# Blackline Development brand assets

This folder is the canonical public-site location for approved Blackline Development brand assets.

## Naming convention
When approved source assets are supplied, Development Operations should normalise them to clear stable names such as:

- `blackline-development-logo-primary.<ext>` — primary full logo/wordmark used in the site header and standard brand applications.
- `blackline-development-logo-mark.<ext>` — standalone mark/icon where an approved mark exists.
- `blackline-development-logo-light.<ext>` — light-on-dark variant only where genuinely distinct from the primary asset.
- `blackline-development-logo-dark.<ext>` — dark-on-light variant only where genuinely distinct from the primary asset.
- `blackline-development-favicon.<ext>` — approved favicon/source icon.
- `blackline-development-social.<ext>` — approved social/share image where supplied.

Do not create duplicate aliases merely for convenience. Keep the smallest useful canonical set and reference those assets from the website.

## Asset handling
- Preserve original quality; do not repeatedly resave/compress source artwork.
- Prefer SVG for logos where an approved vector source exists.
- Use PNG/WebP only where appropriate to the supplied source/use.
- Do not invent, redraw or alter the approved logo merely to fit the current layout.
- If an asset needs a new crop, colourway or derivative, treat that as an explicit brand/design change rather than silently modifying the master.
- Remove superseded temporary assets from the implementation branch once the approved replacements are wired in.

No logo artwork is currently committed here. The site intentionally uses a temporary text wordmark until approved Blackline Development assets are supplied.
